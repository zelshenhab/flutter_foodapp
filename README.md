# Adam & Eve Food App

## Описание проекта

**Adam & Eve** — это мобильное приложение для заказа еды, разработанное на **Flutter**.
Приложение позволяет пользователям просматривать меню, добавлять блюда в корзину, оформлять заказы и отслеживать их статус.

Приложение интегрировано с **кастомным backend API** и поддерживает современные функции мобильных приложений, такие как уведомления, синхронизация корзины и онлайн-оплата.

Приложение опубликовано в **RuStore** и регулярно обновляется.

# Основные функции

## 1. Авторизация пользователя

Пользователь может войти в приложение и получить приветственное уведомление после входа.

Разрешения, используемые приложением:

* Уведомления
* Камера
* Доступ к галерее

Доступ к камере и галерее используется **только если пользователь сам решит загрузить фотографию (например, аватар)**.

---

# 2. Меню и категории

Пользователь может:

* Просматривать категории блюд
* Открывать карточки блюд
* Смотреть подробную информацию о блюде

В последних обновлениях были добавлены:

* Новые категории
* Новые блюда

---

# 3. Корзина

Функции корзины:

* Добавление товаров
* Удаление товаров
* Изменение количества
* Просмотр общей стоимости

Корзина **синхронизируется с backend API**.


# 4. Система заказов

Пользователь может:

* Оформить заказ
* Выбрать способ оплаты
* Просматривать статус заказа
* Открывать детали заказа

Пример запроса создания заказа:

```
POST /api/orders
```

Пример тела запроса:

```
{
  paymentMethod: 'card',
  address: { text: 'Home' },
  notes: 'Самовывоз: заказ из корзины'
}
```

# 6. Система оплаты

Приложение интегрировано с **YooKassa**.

### Процесс оплаты

1. Пользователь создаёт заказ
2. Backend создаёт платёж YooKassa
3. Пользователь переходит на страницу оплаты
4. После оплаты пользователь возвращается в приложение

---

### Поддерживаемые способы оплаты

* Банковская карта через YooKassa

# Разрешения приложения

Приложение может запрашивать следующие разрешения:

* Камера
* Галерея
* Уведомления

Политика использования:

```
Приложение запрашивает доступ к камере и галерее только для загрузки фотографий пользователем (например, аватар профиля).

Приложение не получает доступ к данным без явного согласия пользователя и не использует разрешения в фоновом режиме.

Все действия выполняются только после подтверждения пользователем.
```
